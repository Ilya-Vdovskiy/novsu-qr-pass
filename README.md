# Цифровой пропуск НовГУ

Тестовая PWA студента на Vue 3 и Vite. После входа приложение показывает QR-пропуск и вымышленный профиль студента. Цветовая схема опирается на [фирменный стиль НовГУ](https://edumanagement.novsu.ru/university/about/symbology/).

## Запуск

Нужен Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Нажмите «Войти в демо» или войдите с почтой `student@novsu.test` и паролем `novsu2026`.

Для проверки установки и офлайн-режима запустите производственную сборку.

```sh
npm run build
npm run preview
```

Откройте URL из терминала. Установите приложение кнопкой в шапке или через меню браузера. На iPhone и iPad используйте «Поделиться» → «На экран “Домой”» в Safari. Для установки на другом устройстве опубликуйте содержимое `dist/` на HTTPS-адресе. Установка требует HTTPS или `localhost`, а её доступность зависит от браузера. [Требования к установке PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

## Считывание на проходной

Откройте пропуск и поднесите экран к считывателю. Кнопка «Развернуть» увеличивает QR. Кнопка скачивания сохраняет текущий код в PNG для проверки терминала.

Пропуск создаётся каждые 30 секунд. QR содержит версию формата, UUID установки, TOTP, номер временного интервала, ФИО, год рождения, группу, специальность и встроенную миниатюру вымышленного портрета WebP 36×36. UUID хранится в `localStorage` текущего профиля браузера. Очистка данных приложения создаст новый UUID при следующем входе. Для проверки времени оба устройства используют системные часы.

В производственной сборке service worker кэширует интерфейс, шрифты и портрет. После первой загрузки и сохранения кэша тестовый вход и выпуск QR работают без сети.

## Моки

В этой версии вход и генерация QR работают в браузере. Тестовый ключ TOTP вычисляется из публичного демо-значения и UUID. Для подключения к проходной понадобятся авторизация НовГУ, серверная регистрация устройств, выдача секретов и интеграция с терминалом.

Считыватель передаёт терминалу содержимое QR как JSON в UTF-8. Терминал извлекает `uuid` и `totp` для запроса `POST /enter` с `{ payload: { uuid, totp }, signature }`. [`qr-smocker`](https://github.com/ccrayp/qr-smocker) сопоставляет этот запрос с фиксированными подписанными фикстурами. Запустите сервер по его README и передайте путь к его рабочей копии, чтобы проверить ответы `ACCEPTED` и `REJECTED`.

```sh
node scripts/check-smocker.mjs /path/to/qr-smocker http://localhost:8080
```

Проверка локального прототипа включает вход, постоянство и уникальность UUID, расчёт TOTP, декодирование QR и отклонение просроченных и изменённых кодов.

```sh
npm run check
```

## Изображения

`public/student.webp` и `public/campus.webp` созданы встроенным ImageGen. Промпты описывали студийный портрет вымышленного студента на светло-синем фоне и архитектурную сцену, вдохновлённую историческими зданиями Великого Новгорода, в ультрамариновых тонах.
